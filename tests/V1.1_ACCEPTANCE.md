Fixture: `tests/fixtures/v1.1-task-state.txt`. It began as `PENDING` and was changed by ChatGPT to `READY` after the first documented failure.

**Portability rule:** On Windows, an existing Git checkout may contain `READY\r\n` due to line-ending conversion, even when the Git commit's tracked blob is `READY\n`. A plain `git grep '^READY$' -- file` checks the working tree and can fail because of that CRLF. The cross-platform acceptance test deliberately checks the **committed object belonging to the tested SHA** using `git grep ... HEAD -- file` instead. The real tested commit must always be captured with `git rev-parse HEAD`.
